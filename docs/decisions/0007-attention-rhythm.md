# 0007：注意方向与组织节律

日期：2026-10-01。状态：已实现首版，生命感未验收通过。

用户明确反馈新版仍「boring」「不够智体」。因此停止继续堆叠轨道密度，把重点转到可见的注意、停顿和局部响应；不以新功能数量替代生命感。

- `core/AttentionEngine` 由持久 DNA 种子生成不等时长的组织、停顿、释放节律。输出注意方向、注意强度、信号相位、短脉冲、停顿权重与结构时钟；不依赖 Vue、DOM、Three.js 或 GPU API。
- 靠近时平滑转向指针，首次注意到近处输入产生短脉冲；受惊及困倦抑制注意。桌面核心位置仍锁定，局部形态通过 GPU 弹簧力响应。
- WebGPU 和 WebGL2 使用同一行为参数与共享信号公式。节点信号沿路径传播，注意扇区提亮；停顿时结构时钟和底噪降低，恢复后继续组织。
- WebGPU 使用现有 uniform 缓冲的空位，未增加粒子预算；WebGL2 不增加逐帧临时数组或 CPU 逐粒子更新。
- 本设计属于抽象生命的视觉行为，不表示拥有语言理解、规划或真实推理能力；不接入 AI API，也不改变成长、身份和存档 schema。

系统监听互斥同时收紧：监听连接中/已连接时，禁用文件输入与选择按钮，隐藏播放/暂停；选择器确认时原生侧再次检查，不自动关闭监听。旧轮询结果不能撤回新的监听状态。

验收须区分：确定性与状态边界测试、实际 GPU 运行、真人感知。用户给出的负面体验仍是有效验收反馈，首版行为实现不能直接写成「达到贾维斯效果」。
