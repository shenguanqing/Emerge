# 阶段交付记录模板

本文件仅为记录模板，不代表任何阶段已完成。阶段结束时复制为 `docs/reports/phase-N.md`，填写实际结果并加入文档索引；当前无需创建报告目录或空报告。

## 范围与状态

- 阶段、日期、对应提交：待填写。
- 本阶段实际交付：待填写。
- 完成状态：未验证 / 部分通过 / 通过，依据待填写。
- 未完成项、阻塞原因及对下一阶段的影响：待填写。

## 运行与检查

- 安装、启动、构建与检查命令：按实际工程填写。
- 自动化检查结果：记录命令、结果和失败原因；没有执行的标记未执行。
- 视觉检查：记录观察到的形态、运动、交互与问题，以及截图或录像路径。
