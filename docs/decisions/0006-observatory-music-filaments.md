# 0006：观察空间音乐与粒子光丝

日期：2026-10-01。状态：已实现，桌面全链路及长期验收仍有待测项。

## 背景

观察空间只能查看生命信息，音乐需通过托盘操作。用户希望四个阶段更有科幻感，加入线条并减少散点杂乱。

## 决策

- 音频实例仍由 App 中唯一的 MusicControl 持有，以 Teleport 将控件放入观察空间。侧栏开关不创建/销毁音频实例，音乐不因退出观察空间而停止。
- Web 与桌面均使用本地文件选择；macOS 系统声音使用现有 ScreenCaptureKit。原生 `set_system_audio_enabled` 被托盘与观察空间共用，统一监听开关、菜单勾选与文件播放互斥；权限失败恢复文件操作入口。
- 观察空间是否打开由原生临时状态记录，不能通过改写用户的置顶/穿透偏好表达。设置窗打开时主窗优先穿透；观察空间打开时接收鼠标并取得焦点；关闭后回到用户偏好。macOS 菜单新增观察空间入口，便于穿透状态下使用。
- 原生可接收窗口事件时，画布保留 DOM 双击通道；穿透时仍走全局指针。切换观察空间清空待放行手势，避免两个通道重复开关；侧栏操作不进入全局双击通道。
- 光丝仍由 GPU 粒子表达：部分身体粒子的点精灵沿真实速度的屏幕投影拉成细长剖面。没有固定模型、CPU 逐粒子更新或额外屏幕线框；两种后端采用相同语义。
- 收窄早期流带，减少重复轨道，将成熟轨道数上限从 30 调整为 16；神经连接按节点共享端点并连续重连，形成可读脉络。减少普通散点的亮度，保留光丝与关键节点。
- GLSL 两参数 `atan` 显式转换为 WGSL `atan2`；WebGPU 从顶点阶段传递纵深亮度，不在片元阶段误用倒数裁剪 w。
- 视觉/时间 URL 预览使用真实存档的内存副本。预览仍可读出原有 DNA，但不写回成长或记忆。

## 边界

生命 ID、年龄、成长积分和阶段阈值保持原有语义。小尺寸下不能要求每条脉络均与大图同样可辨；长时性能、实际功耗、穿透下双击与真人生命感不能由编译或逻辑测试替代。实际证据见 [验收记录](../reports/acceptance-2026-10-01.md)。


## 2026-10-01 侧栏工作区续改

「停止」限定为文件音乐停止，系统监听时与选择按钮一并禁用；结束捕获使用「停止监听」。UI 以桌面原生工作区的逻辑像素边距避让菜单栏、刘海与 Dock，不改变全屏粒子画布或核心世界坐标；Web 保留安全区处理。工作区位置与缩放由平台适配层提供，核心不依赖屏幕 API。
