# 开发路线

原则：先做出可运行的最小生命闭环，再扩能力；每个阶段都可运行、可验收。任务只有实现并验收后才勾选；逐条变更明细见 [CHANGELOG](../CHANGELOG.md)，规格与验收标准见 [PRODUCT](PRODUCT.md) / [VISUAL_INTERACTION](VISUAL_INTERACTION.md) / [VALIDATION](VALIDATION.md)。新阶段按编号递增（下一个为 Phase 10c）；小改进与打磨不立阶段，直接实现并记 [CHANGELOG](../CHANGELOG.md)。

## 已知坑

- 参考图线束打磨：已在当前源码浏览器中观察 WebGL2 四阶段与 WebGPU 成熟形态；桌面与 Web 现共用最高 100,000 的粒子预算，活跃数随同一成长/质量档位映射变化；增加后的原生透明桌面层次与长期稳定性尚未复测，不能用浏览器十万粒子截图替代桌面验收。整体细网格密度仍未达到参考图。

- 清晰度：已取消桌面 DPR 1 强制缩放，并修正 30 FPS 上限与质量评估目标不一致导致的误降档。代码/回归通过；真实 Retina 桌面观感和分辨率提高后的负载尚待验证。UI 工具读到旧安装包，未把它当作开发版本验收。

- 视觉版本合入：用户确认撤销最后一轮后的预览没有问题，已将这版源码原样合入默认 `app:dev`；合入时与已确认预览逐字节一致；独立预览入口、代码副本和产物现已移除，只维护默认源码。花屏根因尚未实机单点证实，原最后一轮变更保持撤销，后续勿未经验证重新引入。用户本次确认不等于所有阶段/平台、休眠恢复或长期运行验收，记录见 [CHANGELOG](../CHANGELOG.md) 与 [排查记录](RENDER_INCIDENT.md)。
- 智体视觉：当前组织束、30 轨道映射、1.28 尺度使用本次确认版本；原生小尺寸、全阶段生命感和长期性能仍待专项验收。
- Windows：透明窗口、穿透、托盘、文件播放、原生引导/设置与四语显示尚待目标系统验证；系统音频捕获尚未实现。
- 虚拟桌面：macOS 普通 Spaces 已启用主窗跨桌面配置并完成启动检查；当前自动化无法读取调度中心的桌面列表，A/B 实际切换及隐藏后切换仍待验收。全屏应用独立 Space 与多显示器独立 Spaces 待另测。当前 Tauri 的跨桌面属性不支持 Windows，Windows 虚拟桌面常驻需要独立适配。
- macOS：15.7.9 的透明基座黑底问题保留为历史兼容限制；15.8.1 的复测结果不能外推到更旧或其它系统版本。
- macOS 分发：DMG 已在 ARM64 / macOS 15.8.1 完成打包与结构验证；最新发行包的全新安装/首次启动/声音授权、Intel/通用包、Developer ID 签名与 Apple 公证尚未验收。非沙盒打包时镜像工具需要正常系统磁盘映像服务；受限执行环境可能返回「设备未配置」。
- 原生四语：托盘动态状态与声音权限真实失败场景尚待复测；系统服务项、权限弹窗与系统错误详情遵循操作系统语言。
- 原生输入：CUA 双击事件不等于真实硬件鼠标输入；穿透时的全局 CG 通道与背后应用实际点击落点仍待人工确认，不因自动化进入/退出观察空间而标记通过。
- 跨窗与多屏：上述四项代码问题已修复；跨窗设置/语言在真实组件与模拟 Tauri 事件桥下验证，混合 DPI 已验证 1×/2×/负原点换算。实际原生双窗并存与真实混合 DPI 外接屏操作仍待复测，不将模拟桥或数值测试视为全部实机验收。
- 界面：下拉控件本轮统一为 32px，高度变更须补原生设置窗复测；此前的 WKWebView 菜单/日韩标题走查只覆盖当时版本。
- Web 设置/引导：本轮在开发用 Chromium 内核浏览器（WebGPU / WebGL2，1280×800）完成流程验收；Safari / Firefox、移动端浏览器、生产部署路径与隐私模式（localStorage 不可用降级）未验证。Web 摆放自本轮起生效（生命体按设置停留在浏览器视口内），此前 Web 生命体停在引擎默认位、不受摆放控制。
- 验证证据：原报告中的设备、场景与采样范围已迁入 CHANGELOG；五分钟记录自身未写视口/DPR，Phase 2 的短时帧率和 Phase 9 的升档截图不作为当前性能基线。两小时进程采样未覆盖独立 WebKit/GPU 进程与全应用功耗。
