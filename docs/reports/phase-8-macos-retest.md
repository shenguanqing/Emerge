# Phase 8 macOS 复测（2026-09-30）

复测范围：透明桌面窗口在 macOS 上的合成结果与窗口能力。Windows 不在本次范围。

## 结论摘要

**透明合成已通过。** Phase 8 当时（macOS 15.7.9）确认的 WKWebView 基底黑底问题，在 macOS 15.8.1 上不再复现：Emerge 窗口基底透明，背后窗口内容可完整透出，粒子体以叠加形式显示。无边框、置顶浮层、铺满主屏、托盘入口均正常。

- 日期：2026-09-30；被测产物：`src-tauri/target/debug/bundle/macos/Emerge.app`（构建时间 2026-09-30 21:51，对应工作区源码）。
- 本复测实际检查：透明合成 A/B 对照、窗口层级与几何、粒子体可见性、托盘图标存在性、核心测试。
- 完成状态：macOS 透明合成与窗口能力 **通过**。
- 未完成项：Windows 全线仍无验证环境；混 DPI 多屏、长时间功耗不在本次范围。
