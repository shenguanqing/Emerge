- 环境：macOS 15.7.9 / Apple M1 Pro（16 GB）/ Chrome 146（WebGPU Compute）/ WKWebView（WebGL2 后备）

## 自动化 soak 验收（5 分钟混合场景，页面侧脚本执行）

场景编排：成形 → 闲置 45s（自主生命）→ 缓慢互动 60s（好奇趋近）→ 高速冲击 ×5（受惊-驱散-重组循环）→ 闲置 70s（低功耗调度）。

| 检查项 | 结果 |
| --- | --- |
| 运行错误（JS / GPU） | **0** ✅ |
| 情绪自主转换 | calm ×22 / curious ×13（无输入自主变化；好奇由缓慢互动驱动）✅ |
| 冲击-重组循环 ×5 | 每次冲击后 scatter 触发并按预期消退（采样点衰减至 0.07–0.08）；contract 累积升高后回落（连续受惊的记忆效应）✅ |
| 低功耗调度 | 闲置延长后 60 → 30 → 15 FPS，诊断条实时显示 ✅ |
| 资源稳定性 | WebGL2 路径 Phase 2 实测 programs/textures 恒定；WebGPU 路径本轮未采样（记录为未测）⚠️ |
| Ultra 档 | 100,000 粒子 @ 120 FPS（升档路径自然触发）✅ |
| 三层形态 / 呼吸 / 有机轮廓 | 分帧截图确认（见各阶段报告）✅ |
| 首次靠近迟疑 / 高速驱散 / 2–4 秒重组 | Phase 5/6 实测 ✅ |
