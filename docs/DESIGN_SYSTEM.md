# Emerge 界面设计规范

本规范根据项目提供的视觉参考整理，为 Emerge 自有界面约定。适用于设置、首次引导、观察空间的 DOM 控件与辅助窗口；生命体粒子渲染与沉浸空间原则遵循 [视觉交互规范](VISUAL_INTERACTION.md)，不将纸色背景套到透明桌面或沉浸观察空间。

## 原则

温暖、克制、内容优先。每屏一个主操作；把权限细节、低频选项渐进展开。引导只负责认识、摆放、可选音乐，不强迫授权，不清空生命记录。设置可随时重新打开引导。

## 色彩

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | #FAF9F5 | #262624 |
| 表面 | #FFFFFF | #30302E |
| 下沉区域 | #F0EEE6 | #1F1E1D |
| 主文字 | #141413 | #FAF9F5 |
| 次文字 | #5E5D59 | #C2C0B6 |
| 边框 | #E8E6DC | #3D3D3A |
| 强边框 | #D1CFC5 | #5A5955 |
| 装饰强调 | #D97757 | #E08A6B |
| 实心主按钮 | #A85E43（白字） | #DC8B6C（深色字） |
| 错误 | #B53333 | #E5766F |

控件强调色直接使用生命体主体原色，不统一压暗或降低饱和度。仅强调文字按背景独立调整亮度（浅色不高于 0.13，深色不低于 0.5），实心主按钮自动使用深色或白色文字。设置与引导通过共享 usePaletteAccent 计算，系统主题变化即时响应。装饰强调色不直接作为白字按钮背景；正文对比度至少 4.5:1。状态同时有文字或图标，不能仅靠颜色。

窗口按当前主题声明 `color-scheme`（浅色 / 深色），滚动条等原生控件随之渲染，不被 index.html 的全局设置覆盖。

## 字体与布局

UI 使用系统无衬线字体，中文优先 PingFang SC；引导主标题使用 Georgia / Songti SC / Noto Serif SC 衬线回退。无需下载商业字体。正文 14px / 20px，辅助文字 12–13px，数字用等宽数位；引导标题 26–31px 衬线，设置页 H1 28px、卡片标题 18px。字重 400 / 500 / 600。

4px 间距网格，常用 8 / 12 / 16 / 24 / 32 / 48。引导窗单列内容 440px 居中，正文滚动区全宽、滚动条贴窗口边缘，切换步骤后滚动归零；原生设置窗固定 420×720，不可缩放，Web 设置页适应浏览器宽度。小窗口保留内容滚动，底部操作不覆盖正文；放大文字后所有内容仍可到达。

卡片圆角 12，1px 边框分区，无装饰阴影（弹窗菜单可用 `0 4px 24px rgba(20,20,19,.08)`），悬停仅边框加深。错误放在操作附近，长错误可换行。

## 控件

- 实心主按钮：每屏只设一个，深陶土底或随配色，圆角 9、高 36–38，悬停加深不加投影。
- 描边按钮：1px 强边框的次要入口，悬停转强调色边框与浅强调底。
- 文字按钮：无边框，悬停浅强调底；破坏性操作两段确认——第一次点击进入红色 armed 态，4 秒内再点才执行。
- 下拉选择：语言与界面主题使用自绘 combobox，下沉感暖纸底、1px 细边框、圆角 8 与简洁箭头；触发器统一 32px 高，窄窗不额外增高；菜单行至少 32px 高。展开菜单采用表面色、圆角 10、轻投影，当前项用勾选标记，聚焦/悬停行使用下沉底色。菜单按视口余量向上或向下展开；支持方向键、Home/End、输入检索、回车/空格确认、Esc 关闭和 Tab 离开，外部点击或页面滚动关闭。
- 分段控件：30px 高下沉轨道，选中项表面色 + 1px 内描边 + 轻投影，用于倍率等互斥选择。
- 滑条：4px 圆角轨道、已滑过部分强调色填充、16px 白芯旋钮（悬停放大）；数值只读显示在标签右侧，调整只靠拖动与方向键；自定义色相的轨道即光谱。
- 开关：44×24，仅右侧开关可点，左侧文字为说明；关闭灰、开启强调色。
- 色点：28px 圆形「核白→主体→深晕」径向渐变，选中加双环；自定义色相为锥形光谱小点，选中后展开光谱滑条。配色选择同时提供可读名称，不能仅显示色点。
- 摆放图：下沉底桌面示意，支持拖动、点按与方向键微调，光点带光晕，坐标实时显示。
- 暗色玻璃卡（观察空间专用）：`rgba(14,14,16,.72)` + 18px 背景模糊 + 白色 8% 边框；提示层 `pointer-events: none`，仅按钮可点。
- 操作按钮/图标按钮圆角 8–10px，窄窗下触控目标至少 44px；桌面设置的选择与分段控件采用上述 32px / 30px 紧凑尺寸。聚焦使用 2px 强调色描边和 2px 间隙，仅键盘聚焦显示；禁用操作附原因。移动端触控规范在对应阶段另行评估。

## 设置窗（420×720）

从上到下：**外观**（粒子团大小 / 亮度 / 粒子点大小滑条；配色色点 + 自定义色相与光谱滑条）→ **行为**（置顶、鼠标穿透开关与说明）→ **桌面位置**（摆放图 + 坐标读数）→ **成长**（成长度与统计、四阶段节点可点预览说明、「怎么积累」折叠）→ 隐藏的**时间加速**（连点页脚提示 5 次解锁：虚拟时钟、倍速分段、两行操作，重置生命两段确认）→ 页尾**通用**（语言与界面主题下拉选择；重新查看引导为描边按钮、恢复默认为文字按钮，空间足够时左右对齐，窄窗或长文案允许换行）。

## 引导窗（560×640，最小 360×420）

顶部常驻舞台：粒子球（体型与配色实时预览，双击触发观察空间演示）、品牌字标、圆点步骤指示、两态演示提示，右上「先去设置」。内容列三步：

1. 认识：欢迎标题、简短介绍、三条互动提示卡。
2. 摆放：大小、配色（含自定义色相）、桌面位置即时应用；说明穿透行为。
3. 音乐：可选本地文件或系统声音，权限说明折叠，未开启也能完成。

页脚为上一步 + 实心主按钮。所有步骤可后退、跳过；切换步骤后焦点落在新标题、滚动归零；不将整个正文设为动态播报区域。完成返回设置；重新打开不重置生命、DNA 或成长。浏览器提供同样入口，桌面专属能力说明不可用原因。

## 观察空间界面

遵循视觉交互规范的沉浸原则：信息只占边缘，不做仪表盘，不干扰生命体。右侧信息栏（暗色玻璃卡）：随语言翻译的观察空间眉标 + 标题 + 关闭按钮，使用日 / 状态 / 能量 / 信任，DNA 五项，成长与陪伴时长，音乐面板（错误就近显示），底部复位视角与操作提示行。首访操作提示卡出现在左下角，一次性淡出并按设备记忆，不再重复显示。Esc、双击或关闭按钮退出；状态即时生效，设置中的破坏性操作（重置生命）明确后果并两段确认。

## 动效与文案

微交互 120–160ms，展开与淡入淡出 200–250ms，缓动 `cubic-bezier(.2,0,0,1)`。尊重 `prefers-reduced-motion`，界面不使用循环装饰动画（生命体自身的呼吸与节律属于行为，不在此列）。

文案平和直接，按钮用动作短语；权限说明按需出现，错误写清问题和恢复方式。界面支持中文 / English / 日本語 / 한국어；前端、托盘、应用菜单、窗口标题与应用生成的错误说明共用 `src/i18n/messages.json` 四语词表。阶段名称在中/日/韩使用当地语言，英文保留 Origin 系列形态名。品牌、DNA、GPU 后端名与技术单位保留原名；系统提供的文件选择器按钮、权限弹窗、服务菜单与系统错误详情由操作系统本地化。长文案不挤压按钮。

## 验收

实际查看浅色、深色、窄窗（360 / 420）与中英文布局；走查设置与引导全部步骤、Tab 与方向键、200% 缩放；观察空间检查暗色对比度与提示卡行为。设计目标不代表现有控件全部达标，具体完成情况按日期记录在根目录 [CHANGELOG](../CHANGELOG.md)。
