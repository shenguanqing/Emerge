# 验收与验证计划

本文件定义验收方法与标准；各轮实际结果按日期记入根目录 [CHANGELOG](../CHANGELOG.md)，未验证项汇总见 [ROADMAP.md](ROADMAP.md)。

## MVP 体验

- 启动时粒子逐渐出现并凝聚，最后形成持续呼吸的生命体。
- Core、Body、Aura 具有层次，轮廓有机；允许接近球形的饱满粒子体，不能只是一团均匀封闭的硬球壳。
- 不操作时有自主变化，无明显固定循环；操作后反馈与输入强弱相关。
- 首次靠近呈现约 200–500ms 迟疑，高速划过产生明显驱散。
- 驱散期间核心仍在，目标约 2–4 秒以力场自然重组。
- 重组后暂时提高回避距离，情绪逐步恢复。
- 透明桌面无黑色矩形或明显合成脏边，基本交互与退出入口可用。

邀请试用者自由观察和互动 5 分钟，记录是否主动继续玩、是否感知到注意/惊吓/恢复，以及认为机械或廉价的片段。记录人数和反馈原文，不把单次主观判断冒充普遍结论。若生命感不成立，暂停成长等后续功能。

## 四形态视觉

- `?growth` 或真实成长度下 Origin / Awaken / Conscious / Emerge 四档均可辨，且能认出是同一母体在成长。
- 任一阶段不得出现固定实体球模型、均匀封闭硬球壳、多组竞争的宏观环、硬几何圆环、机械网格或整团过曝；数据弧须保留可见大断口与参差末端；近球形轮廓本身不作为失败依据。
- 保留同一个中央组织核；Awaken 的径向纤维、局部球层与卷流仍可辨，不能让全部粒子长期停在两类锚点中间糊成云。
- Origin 初生期已有密小芽核与实际颗粒厚度；成长后内部弯曲组织束扩展到内层，改变观察角度时仍能读出内部体积，不能只剩外围线框。内部信号须沿组织束的实际路径传播，颗粒与暗缝仍可辨。
- Conscious 可读出断续片区、径向路径、数据弧形成与局部亮包；Emerge 须看到球体、不均匀三维径向束、中央卷曲核、横向通道与数据弧的主次。连续观察自转与独立环流，检查三层片区错位和暗隙、数据弧大断口不被伴随流补齐、热点光晕和短尾迹不遮盖球层；成熟程度不以曝光或环丝数量单独判定。
- 结合参考视频和球层图片检查数据弧相对球体的大小、径向束的三维覆盖、中央亮核及球层厚度。改变视角后仍应有体积，不能只剩平面花瓣；近远层、局部暗缝与能量路径保持可读。
- 记录相同后端、阶段和质量下的活跃粒子数，检查内部填充使用已有预算；体积、主路径和外膜的密度与明暗层次分别可读。参考图只用于视觉语法对照，不据单张图片推断其制作技术或粒子数量。
- 观察靠近→局部聚焦→短暂回应→停顿，以及高速划过→保核驱散→力场重组；信号的亮点须对应实际路径，不能只随机撒点或整团闪烁。
- WebGPU 与 WebGL2 结构族一致；特别检查从活跃转入 30/15 FPS 后核心保持集中，无外围持续外逸；桌面透明小尺寸与不同背景下核心和轮廓另行验收。
- 交互与音乐响应在四形态下均可用，质量降档不改变形态身份。
- 对比相同相机、体型百分比与阶段下的整体尺寸，按 [ARCHITECTURE](ARCHITECTURE.md) 的世界尺度映射检查进一步放大的目标；设置和引导仍显示 10–100%，分别检查最小值、默认值与最大值，保存重启后百分比不变。同步检查屏幕边缘裁切、局部聚焦和驱散后的回收范围，不能因放大遮盖退出入口或丢失粒子。

## 兼容与性能

| 测试面 | 目标 / 方法 |
| --- | --- |
| Apple Silicon Mac | 活跃场景目标稳定 60 FPS，记录机型、系统、分辨率与画质 |
| Windows 集显 | 活跃场景目标至少 30 FPS，记录 GPU 型号与驱动 |
| Web | 记录浏览器版本，分别测试 WebGPU 和 WebGL2 |
| 桌面 | macOS / Windows 分别测试透明窗口、alpha 后处理、输入和生命周期 |
| 虚拟桌面 | A→B→A 切换后同一粒子团继续可见、位置稳定；置顶开/关及设置/引导打开关闭后重测；托盘主动隐藏后切桌面仍隐藏，再显示可恢复 |
| 自适应质量 | 持续负载下可降档，恢复后谨慎升档，无频繁振荡或突变 |
| 常驻 | 无交互时验证 60 → 30 → 15 FPS 调度，交互后恢复 |
| 恢复 | 隐藏、最小化、休眠与 GPU 设备/上下文丢失后可恢复或明确提示 |

建议统一运行预热、平静、连续驱散和闲置场景；初始采用 1 分钟预热、3 分钟活跃与 5 分钟闲置的记录窗口，再按问题调整。采集平均 FPS、P95 帧时间、粒子数、像素比、后端、CPU/GPU 占用及内存趋势。平均 FPS 达标不能掩盖持续卡顿。

GPU 占用与功耗只能依据可用系统工具实测；无法获得时标记未测。检查长时间运行和重复挂载/卸载后的资源趋势，确保没有持续增长。

虚拟桌面记录操作系统、普通桌面数量与切换方法；新建/删除桌面、全屏应用独立 Space、多显示器独立 Spaces 分开记录，不将普通 A/B 切换结论外推到这些场景。

## 自动化验证边界

- 四语界面：`pnpm test:i18n` 检查中/英/日/韩词条集合、空值、重复键、插值参数一致性，以及前端/Rust/Swift 引用与动态选项覆盖；原生语言标识必须区分日/韩，不能折叠成英文。实际走查设置/引导/观察空间、托盘与应用菜单，记录语言切换、记忆、键盘和浅深色/窄窗效果。品牌与技术标识保留原名，系统弹窗与服务项遵循系统语言。
- 核心测试：时间步上限、情绪平滑、状态边界、反应延迟、固定种子复现和质量档位滞回。
- 集成验证：能力探测与后端切换、输入坐标变换、窗口生命周期、GPU 资源释放。
- 跨窗口设置：欢迎与设置并存，先在设置改亮度/点大小/行为，再在欢迎改配色/体型/位置，检查存档与界面均保留最新值；交换操作顺序、保留当前帧编辑及恢复默认另测。语言切换须检查欢迎正文，卸载后不再接收事件；混合 DPI 换算与真实外接屏操作分别记录。模拟事件桥只能证明组件协议，不替代原生多窗实测。
- 持久化测试：schema 迁移、DNA 稳定、损坏恢复、时间倒退与超长离线；具体覆盖随实现维护，长期真人使用另行验收。
- 主界面与工具入口：普通 URL 与 `?debug=1` 保持相同的设置/音乐/运行状态入口，无底部诊断条或浮动面板；时间工具只在 debug 的运行状态弹层下追加。运行状态检查后端、FPS、粒子数、质量、DPR 和生命信息，关闭/外部点击/Esc 行为一致；检查窄屏滚动和按钮可达。设置页连点页脚 5 次仍可展开共享时间控件。普通入口验收真实首次引导；debug/形态/时间预览不写真实生命或跨标签页时钟快照，调倍率、前进时间、增加互动与两段确认重置后，普通入口的 Life ID / 成长应保持原记录。不在普通会话执行验收重置。
- 视觉与真实性能必须在实际渲染环境检查，不能仅依赖单元测试或构建成功。

## 结果记录格式

每次验证记录：日期、提交、设备/系统、浏览器或 WebView、后端、分辨率、粒子数、质量、场景、测量时长、结果、截图/录像位置及未验证项。不填写编造的基线数据。

验证版本使用提交哈希或工作树标识；不适用的字段写「不适用」，缺失的环境写「未读取/未记录」。历史证据不足时保留观察范围，并在 ROADMAP 记录限制，不将旧结果外推到当前版本或全部平台。
