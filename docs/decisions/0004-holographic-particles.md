# 0004：参考贾维斯的全息粒子形态

日期：2026-09-30。依据用户提供的金橙球形全息参考图。

以多层倾斜环轨、三条主环、径向脉络及断续段代替松散云状锚点。外观只使用 GPU 粒子，未增加球体网格或贴图模型。每个种子的目标位置随时间、成长和呼吸缓慢变化，模拟使用弹簧力、阻尼和交互力推进，不把位置直接赋值为目标。

HologramField.ts 保存共享数学表达式并生成 GLSL/WGSL，减少后端形态漂移。提高轨迹附近恢复力，降低平静流场扰动，保留声音和指针响应。贾维斯主题降低白色混入，使用金橙核心、橙色主体与暗琥珀外围。

成长数据和阶段阈值保持不变，视觉成熟改为轨迹内部细节增加，不再通过大双瓣和向外伸展表达。此前“阶段必然对应双核外观”的描述不再适用于此新样式。后续验证以图像相似度、层次、声音/鼠标响应与桌面小尺寸可读性为准，不宣称电影效果逐像素复刻。
